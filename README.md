# Atividade Avaliativa - Revisão de POO (Java)

Repositório contendo exercícios práticos e materiais de revisão de Programação Orientada a Objetos em Java.

## Estrutura do Projeto

- `src/questao3`: Modelagem de Faculdade, Curso e Aluno.
- `src/questao4`: Composição de componentes (Celular, Processador, Memória, Tela, Jogo).
- `src/questao5`: Sistema bancário básico (Banco, Conta, Cliente).
